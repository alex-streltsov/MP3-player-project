# MP3-player-project
многомодульное клиент-серверное приложение на языке программирования Java в среде разработки Apache NetBeans. Приложение  представляет собой сетевой MP3-проигрыватель с интуитивно понятным графическим интерфейсом для клиентской части и панелью администрирования для серверной части.
